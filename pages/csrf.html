Profile Update Endpoint — No CSRF Token, No Origin Verification

⚠ High Severity
🧪 Lab Objective — CSRF Attack

The profile update form submits to POST /api/csrf-update with no CSRF token and no SameSite cookie. A malicious external page can silently submit this form on behalf of a logged-in user.

  • The attack page generates a hidden form pointing to this endpoint
  • When a logged-in user visits the attacker's page, their profile updates automatically
  • No interaction needed — auto-submits on page load
  • Use the "Generate CSRF PoC Page" button to create the attack HTML

Vulnerable vs Secure Code

// ❌ VULNERABLE — no CSRF protection app.post('/api/csrf-update', (req, res) => { updateUser(req.body); // No token check, any origin allowed res.json({ success: true }); }); // ✅ SECURE — validate CSRF token app.post('/api/csrf-update', csrfMiddleware, (req, res) => { if (req.body.csrf_token !== req.session.csrf_token) { return res.status(403).json({ error: 'Invalid CSRF token' }); } updateUser(req.body); }); // Also set: Set-Cookie: session=...; SameSite=Strict; HttpOnly
