About This Lab

This lab simulates a hospital management system (MediCare Pro) that is intentionally vulnerable to the OWASP Top 10 and common web attacks. Each module provides a realistic attack surface modeled after real-world healthcare applications. The vulnerabilities are purposely introduced for educational use in penetration testing, cybersecurity courses, and security awareness training.

🔴 Critical Vulnerabilities

SQL Injection, Blind SQLi, File Inclusion, Command Execution, Shell Upload

🟠 High Vulnerabilities

Brute Force, XSS Reflected, XSS Stored, CSRF
